# ncaleague frontend

## Usage

Before running any other command, make sure you have installed all the dependencies with `npm install`.

Common commands you may use:

`npm run dev`: start a dev server

`npm run lint`: lint the project

`npm run build`: bundle the frontend for deployment

`npm run serve`: preview a built bundle

## Tech stack

JS framework: React

Package manager: NPM

Bundler: Vite

Styling: Tailwindcss

Testing: Vitest

Linting: ESLint

Formatting: Prettier
